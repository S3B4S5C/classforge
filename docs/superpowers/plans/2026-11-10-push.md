# Web Push ClassForge — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Push web/Android conectadas a notificaciones persistidas de ClassForge.
**Architecture:** VAPID+SW, Mongo outbox transaccional, TWA delegation oficial.
**Tech Stack:** Java21/Spring/Mongo, Angular22, Web Push5.1.2, Android Browser Helper2.7.4.
**Spec:** `docs/superpowers/specs/2026-11-10-push-design.md`.

## Global Constraints

- Mantener origen Azure/paquete/firma, rama `tiago`, eventos actuales y roles.
- Ninguna clave privada en frontend, APK, Git ni logs. API existente sigue protegida.
- Feature desactivada salvo configuración completa; red fuera de transacción UML.
- Suscripciones propias, cambios de cuenta seguros, permisos solo por acción.

## Review Focus

1. Endpoint malicioso/redireccionado → no SSRF.
2. Logout/cambio de cuenta/carrera de permiso → no avisos de otra cuenta.
3. Commit fallido o proceso reiniciado → no envío adelantado/pérdida silenciosa.
4. Proveedor lento/404/410/429/5xx → bajas/reintentos acotados sin afectar UML.
5. Click malicioso, payload o permiso inválido → fallback interno/estado claro.
