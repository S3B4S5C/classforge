# Azure Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** Dejar un artefacto completo y herramientas reproducibles para Azure.
**Architecture:** App Service Java21, Angular embebido y MongoDB Atlas, una instancia.
**Tech Stack:** Spring Boot4, Gradle9, Angular22, Node24, PowerShell, Bicep.
**Spec:** docs/superpowers/specs/2026-11-09-azure-design.md.

## Global Constraints

- No crear recursos Azure, ni modificar bases habituales.
- Mantener API/STOMP JWT y pipeline preview/BATCH/Apply.
- Cambios de hosting SPA opt-in; no afectar modo local/AWS.
- Un solo backend; secretos fuera del artefacto y Git.

## Review Focus

- Rutas profundas Angular cargan; GET API privado sigue 401 y no entrega HTML.
- Assets públicos y métodos HTTP no amplían acceso al backend.
- Build no arrastra assets antiguos cuando se omite frontendDist.
- Los parámetros y outputs de infraestructura no revelan secretos.
- Infraestructura/CI no despliegan automáticamente con push.
