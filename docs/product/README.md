# Producto

`product.md` es la especificación maestra del **producto objetivo** ClassForge.

Una capacidad descrita en `product.md` no implica por sí sola que ya exista en el software.

Para conocer el estado real consultar:

- `../puds/current-status.md`;
- `../puds/use-cases.md`.

Para el Word final esta carpeta alimentará principalmente visión, alcance, requisitos, restricciones, características y decisiones de producto.
