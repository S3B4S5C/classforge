# Ciclos PUDS

En ClassForge, **Ciclo = iteración PUDS**.

Cada archivo de esta carpeta resume una iteración desde el punto de vista del proceso:

- objetivo;
- fase;
- casos de uso trabajados;
- riesgos;
- incrementos técnicos;
- decisiones;
- pruebas;
- criterios de salida;
- deuda o trabajo posterior.

La evidencia técnica granular vive en `../iterations/`.
