# C1 — CU-01 Crear proyecto

**Ciclo:** 1  
**Estado:** cerrado

## Resultado

El usuario autenticado puede crear un proyecto persistente con identidad UUID y ownership.

El proyecto queda disponible en su biblioteca y sirve como raíz para `ProjectDocument`.

## Evidencia

- backend de proyectos;
- persistencia JPA;
- UI de biblioteca/creación;
- aislamiento por owner.
