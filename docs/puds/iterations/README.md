# Incrementos técnicos

La carpeta `iterations/` contiene evidencia técnica granular.

La narrativa PUDS de alto nivel vive en `../cycles/`.

## Convención de nombre

```text
C<n>-cu<XX>-<incremento>-descripcion.md
```

Ejemplo:

```text
C1-cu08-002-local-voice-whisper.md
```

Significa Ciclo 1, CU-08 e incremento técnico 002.

Los prefijos históricos `E1` y `E3` utilizados durante el desarrollo se normalizan a `C1` al cerrar el primer ciclo. El contenido histórico no se descarta.
