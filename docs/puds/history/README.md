# Historial PUDS

Esta carpeta conserva documentos que tuvieron valor durante la ejecución pero que ya no son la fuente normativa del estado actual.

Regla:

- los documentos de `history/` pueden contener planes superados y frases como "siguiente CU";
- no deben utilizarse para determinar el estado actual;
- `../current-status.md` gobierna el estado;
- `../use-cases.md` gobierna la especificación vigente;
- `../cycles/` gobierna la narrativa de los ciclos ejecutados.

El archivo `use-cases-pre-cycle1-normalization-2026-08-28.md` conserva la bitácora acumulativa existente antes del cierre documental del Ciclo 1.
