# Runtime

Documentación operativa de ejecución local.

- `assistant-local.md`: arranque conjunto de llama.cpp y whisper.cpp, puertos y pre-demo.
- `whisper-local.md`: configuración específica de whisper.cpp y modelos STT.

Esta carpeta no define arquitectura de dominio ni estado PUDS. En CU-27 contiene además el runbook ejecutable de la fase de Transición.
