# Despliegue Azure

El destino elegido es una **VM Azure**. Seguir la [guía VM vigente](azure-vm-deployment.md).
Incluye infraestructura, bundle, nginx HTTPS/WSS, systemd y verificación.

La preparación anterior de [App Service](azure-app-service-deployment.md) queda como alternativa.
Sus comandos de publicación no se utilizan para la VM.
